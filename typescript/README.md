# zimbabwe_plate

Zimbabwe's licence plates for plate_core — three letters and four digits on one row or stacked, in black on yellow or white and red on white, with an advisory validator.

## Quick start

### Install (TypeScript)

Copy `typescript/src/countries/zimbabwe/` into `plate_core/typescript/src/countries/`.

Then run the tests from `plate_core/typescript/`: `npm test`.

### Use

```ts
import country from './countries/zimbabwe';

const spec = country.specs.get('zw.row');
console.log(country.package);
```

## Specs

The specs are the same in every language (they come from shared data).

- `zw.row`
- `zw.stacked`

## Themes

- `ZimbabweThemes.yellow`
- `ZimbabweThemes.yellowStacked`
- `ZimbabweThemes.white`
- `ZimbabweThemes.commercial`

## Change it

- Specs: `country.specs`, by id.
- Themes: `country.themes`.
- Validators: `country.validators` (`ZimbabweValidator`).
